# Changelog

All notable changes to this project are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-14

### Added

- Initial release of the `codebase-setup` skill package.
- State-driven workflow that closes the gap between a target baseline and the repository's current state.
- `scaffold`, `harden`, and `audit-only` modes.
- Archetype, stack, depth, and module classification with runtime discovery and documentation research.
- Consent gates for toolchain, global tools, source initialization, dependencies, and `AGENTS.md` / `DESIGN.md`.
- Canonical `AGENTS.md` template with mandatory preview and consent.
- Google Stitch / Google Labs `DESIGN.md` specification and template for frontend/UI applications with YAML design tokens and 8 core Markdown sections.
- Standard project file templates: `.editorconfig`, `CONTRIBUTING.md`, and `SECURITY.md`.
- Multi-platform plugin distribution manifests for Antigravity, Claude Code, and Agents CLI.
- Verification and reporting contract with evidence rules.
