# Security Policy

## Supported Versions

Only the latest release branch is currently supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < Latest| :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this project:

1. **Do not disclose the issue publicly** (e.g., via public GitHub issues, discussions, or social media).
2. Report the vulnerability privately to the maintainers or via the repository's Private Vulnerability Reporting feature on GitHub.
3. Please include:
   - A detailed description of the vulnerability.
   - Steps to reproduce the issue or a minimal proof of concept (PoC).
   - Potential impact and affected components.

We will acknowledge receipt within 48 hours and work with you on a timeline for a coordinated disclosure and patch.
